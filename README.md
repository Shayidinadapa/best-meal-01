A tiny program that writes one sentence — the best meal I ever had — to `/output/entry.txt`.

## How it works

`main.ts` writes a single sentence (under 200 characters) about sate kambing eaten at a roadside tent stall while heavy rain drummed on the tarp above. It is deterministic: no network, no input, no randomness — the same sentence every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later.
